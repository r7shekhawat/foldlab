Hinge clearance

Edited today

When a screen folds, the seam splits what the user sees into two regions. A layout that ignores the seam lets sentences run straight across it, and some dual-screen devices hide a strip of pixels there, so characters simply disappear.

A fold-aware layout gives each region a job. On a book fold the list sits on one side and the open note on the other. In tabletop posture the content rises to the top half and the controls rest on the bottom half.
